# George Strait Fan Hub — GitHub Pages

This is a static, mobile-first fan website.

## Important
This project is intentionally labeled as an independent fan-made website. Do not present it as official George Strait management, official ticketing, or an authorized merchandise store unless you have written authorization.

## Files
- `index.html` — website
- `styles.css` — design
- `script.js` — cart, options and Zangi handoff
- `assets/` — supplied George Strait images and product showcase

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `george-strait-fan-hub`.
2. Upload the contents of this folder (not the ZIP itself).
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your Pages URL.

## Zangi
The confirmation button opens the supplied Zangi conversation:
https://services.zangi.com/dl/conversation/6727254150

The site copies the order summary to the clipboard when supported. The visitor can paste that message into the Zangi conversation.
